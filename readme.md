# 1C BSL to llms.txt Generator

Универсальный консольный инструмент для автоматической генерации контекстной документации в формате `llms.txt` и Markdown-файлов по любым конфигурациям платформы 1С:Предприятие 8.3 для корпоративных RAG-систем.

## Назначение

Прямая передача сырых XML-выгрузок и BSL-файлов в языковые модели приводит к перегрузке контекстного окна техническим шумом (GUID, визуальные свойства форм, XML-теги)[cite: 1]. 

Генератор обеспечивает:
- Очистку контекста от избыточных служебных тегов с сохранением публичного API: сигнатур процедур и функций, параметров, типов и комментариев BSLDoc.
- Построение универсальной двухуровневой структуры по стандарту llmstxt.org: корневой манифест-навигатор `llms.txt` и каталог атомарных Markdown-файлов.
- Семантическое обогащение описаний русскоязычными синонимами объектов из XML-метаданных.
- Инкрементальную сборку базы знаний с кэшированием по MD5 для мгновенной повторной обработки тяжелых конфигураций.

## Архитектура решения

Инструмент реализует концепцию двухэтапного поиска (Agentic Retrieval):
1. **Навигационный уровень (`llms.txt`):** Корневой реестр со списком всех подсистем, модулей и их кратким назначением. Служит картой для модели при определении нужного контекста.
2. **Уровень документации (`docs/`):** Атомарные `.md` файлы по каждому модулю или объекту с подробным описанием сигнатур, типов данных и примеров вызова.

## Технологический стек

- Язык: Python 3 (стандартные библиотеки: `re`, `os`, `xml.etree.ElementTree`, `hashlib`, `json`)
- Стандарты разметки: Markdown, спецификация llms.txt
- Поддерживаемые СУБД для векторизации: PostgreSQL + pgvector, ChromaDB, Qdrant

## Использование

### Требования
- Python 3.8+
- Выгрузка любой конфигурации 1С:Предприятие (в формате выгрузки Designer или EDT)

### Запуск генератора

Передайте путь к каталогу с файлами конфигурации в качестве аргумента:

python parse_bsl.py <ПУТЬ_К_ПАПКЕ_КОНФИГУРАЦИИ>


### Результат работы

В корне проекта или целевой директории формируется готовый комплект документации:
- `llms.txt` — корневой файл-манифест для RAG-агентов.
- `docs/` — структурированный каталог с Markdown-описаниями модулей метаданных.
- `.bsl_cache.json` — реестр контрольных сумм для инкрементального обновления.
