### <a name="записатьсобытиявжурналрегистрации"></a>ЗаписатьСобытияВЖурналРегистрации

- **Тип:** Процедура
- **Сигнатура:**
  ```bsl
  Процедура ЗаписатьСобытияВЖурналРегистрации(СобытияДляЖурналаРегистрации) Экспорт
  ```
- **Описание:**

  Процедура пакетной записи сообщений в журнал регистрации.
  После записи переменная СобытияДляЖурналаРегистрации очищается.

  Для добавления сообщений на клиенте следует использовать процедуру
  ДобавитьСообщениеДляЖурналаРегистрации общего модуля ЖурналРегистрацииКлиент.

  Для немедленной записи очереди сообщений с клиента следует использовать процедуру
  ЗаписатьСобытияВЖурналРегистрации общего модуля ЖурналРегистрацииКлиент.

  Параметры:
   СобытияДляЖурналаРегистрации - см. ЖурналРегистрации.ЗаписатьСобытияВЖурналРегистрации
