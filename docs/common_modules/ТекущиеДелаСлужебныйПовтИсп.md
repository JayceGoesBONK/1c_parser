### <a name="принадлежностьобъектовразделамкомандногоинтерфейса"></a>ПринадлежностьОбъектовРазделамКомандногоИнтерфейса

- **Тип:** Функция
- **Сигнатура:**
  ```bsl
  Функция ПринадлежностьОбъектовРазделамКомандногоИнтерфейса() Экспорт
  ```
- **Описание:**

  Возвращает соответствие объектов метаданных и подсистем командного интерфейса.

  Возвращаемое значение: 
   Соответствие из КлючИЗначение:
     * Ключ - Строка - полное имя объекта.
     * Значение - Массив из Строка - полные имена подсистем командного интерфейса программы,
                                     в которые входит данный объект.
