### <a name="важностьпоумолчанию"></a>ВажностьПоУмолчанию

- **Тип:** Функция
- **Сигнатура:**
  ```bsl
  Функция ВажностьПоУмолчанию() Экспорт
  ```
- **Описание:**

  Значение важности ключевой операции по умолчанию (устанавливается для новых ключевых операций).

  Возвращаемое значение:
   Число(1) - важность ключевой операции по умолчанию.
