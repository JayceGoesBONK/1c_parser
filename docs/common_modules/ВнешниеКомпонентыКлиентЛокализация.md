### <a name="поисккомпонентынапортале"></a>ПоискКомпонентыНаПортале

- **Тип:** Процедура
- **Сигнатура:**
  ```bsl
  Процедура ПоискКомпонентыНаПортале(Оповещение, Контекст) Экспорт
  ```
- **Описание:**

  Параметры:
   Оповещение - ОписаниеОповещения
   Контекст - Структура:
       * ТекстПояснения - Строка
       * Идентификатор - Строка
       * Версия        - Строка
                       - Неопределено
       * ОбновлятьАвтоматически - Булево
