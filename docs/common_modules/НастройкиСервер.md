### <a name="установитьтекущуюстраницу"></a>УстановитьТекущуюСтраницу

- **Тип:** Процедура
- **Сигнатура:**
  ```bsl
  Процедура УстановитьТекущуюСтраницу(ИмяОбъекта, ГруппаСтраниц, ИмяСохраненнногоЗначения) Экспорт
  ```
- **Описание:**

  Установка текущей страницы (закладки) для форм, имеющих
  несколько закладок
