### <a name="навигационнаяссылканастандарт"></a>НавигационнаяСсылкаНаСтандарт

- **Тип:** Функция
- **Сигнатура:**
  ```bsl
  Функция НавигационнаяСсылкаНаСтандарт(Ссылка) Экспорт
  ```
- **Описание:**

  Получить навигационную ссылку на указанный стандарт.

  Параметры:
   Ссылка - СправочникСсылка.Стандарты - ссылка на стандарт.

  Возвращаемое значение:
   Строка - навигационная ссылка на указанный стандарт.
